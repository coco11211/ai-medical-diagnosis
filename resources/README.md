# Application Resources

This directory contains application resources for the Windows application.

## Icon Requirements

### icon.ico
The main application icon used for:
- Application window
- System tray
- Desktop shortcut
- Taskbar
- Installer

**Requirements:**
- Format: ICO
- Sizes: 16x16, 32x32, 48x48, 64x64, 128x128, 256x256 pixels
- Color depth: 32-bit with alpha channel

### Creating an Icon

You can create an icon using:

1. **Online Tools:**
   - https://convertio.co/png-ico/ (Convert PNG to ICO)
   - https://www.favicon-generator.org/
   - https://icoconvert.com/

2. **Desktop Software:**
   - GIMP (Free, open-source)
   - Adobe Photoshop
   - Inkscape (for vector graphics)

3. **Quick Solution:**
   Create a 256x256 PNG with your logo, then use an online converter to create the ICO file with multiple sizes.

### Recommended Design:
- Simple, recognizable design
- Works well at small sizes (16x16)
- Contrasts well with light and dark backgrounds
- Represents trading/finance theme
- Professional appearance

### Placeholder Icon:
Until you create a custom icon, you can:
1. Use a stock icon from free icon sites (with proper licensing)
2. Generate a simple icon with your app initials
3. Use the default Windows application icon (will be auto-generated by PyInstaller)
